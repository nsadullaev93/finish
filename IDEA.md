# Финиш — приложение для быстрого закрытия ипотеки

> Рабочее название. Личное приложение для iPhone, которое показывает путь к полному закрытию ипотеки и потребительского кредита и помогает найти деньги на досрочное погашение. Решения всегда принимает пользователь: приложение только считает и подсказывает.

---

## 1. Главная идея

На главном экране один вопрос и один ответ: **«Когда я буду свободен от долгов?»** Крупный год закрытия, прогресс выплаты и одна понятная подсказка, как приблизить этот год.

Всё остальное (кредиты, траты, сценарии) работает на этот ответ.

## 2. Исходные условия

| Параметр | Решение |
|---|---|
| Платформа | iPhone |
| Кредиты | Ипотека + потребительский кредит (структура позволяет добавить и другие) |
| Тип платежа | Аннуитетный |
| Досрочное погашение | Всегда два варианта рядом: **уменьшить срок** и **уменьшить платёж** |
| Учёт трат | Вручную, по мере трат (каждый день или раз в неделю) |
| Доход | Зарплата 1–2 раза в месяц + нерегулярные премии |
| Подушка безопасности | Не нужна |
| Подсказки | Простые прозрачные правила, без ИИ |
| Тема | Светлая/тёмная, переключается вслед за системой |
| Хранение данных | Только на устройстве, без аккаунтов и серверов (iCloud-резервная копия — позже, по желанию) |
| Валюта | Рубли |

## 3. Экраны

Навигация: нижняя панель вкладок, как в приложениях Apple. Четыре вкладки.

### 3.1. Главная — «Путь к финишу»

- **Крупно:** год и месяц полного закрытия ипотеки (например, «Март 2041»).
- **Кольцо прогресса** (в духе колец «Активности»): сколько процентов основного долга уже выплачено.
- Три числа под кольцом:
  - **Выплачено** — сумма основного долга, погашенная с начала кредита.
  - **Осталось** — текущий остаток долга.
  - **Проценты впереди** — сколько ещё уйдёт банку при текущем графике.
- **Свободно в этом месяце:** сколько можно направить на досрочку (см. раздел 5).
- **Одна главная подсказка** (см. раздел 6).
- Небольшая карточка потребительского кредита: остаток и дата закрытия.

### 3.2. Кредиты

- Список кредитов, у каждого карточка с остатком, ставкой, платежом, оставшимся сроком и датой закрытия.
- Добавление и редактирование кредита: остаток долга, годовая ставка, ежемесячный платёж, оставшийся срок (месяцев) и дата очередного платежа.
- **Журнал досрочных погашений:** дата, сумма и выбранный режим (срок или платёж). После каждой записи график пересчитывается.
- График остатка долга во времени: фактическая линия и прогноз.

### 3.3. Сценарии — «Что если?»

Ключевой экран для принятия решений.

- Быстрые кнопки: **+5 000 ₽, +10 000 ₽, +20 000 ₽** в месяц, а также своя сумма (ползунок).
- Отдельно **разовое погашение**: «Что если внести премию 100 000 ₽ сейчас?»
- Для каждого сценария две колонки рядом:

| | Уменьшить срок | Уменьшить платёж |
|---|---|---|
| Дата закрытия | … | … |
| Срок сокращается на | … лет … мес | — |
| Новый платёж | прежний | … ₽ |
| Экономия на процентах | … ₽ | … ₽ |
| Остаётся на жизнь в месяц | … ₽ | … ₽ |

- График: текущая линия остатка долга и линия выбранного сценария, разница между ними закрашена.
- **Распределение между кредитами.** Если досрочные деньги можно отдать и в ипотеку, и в потребительский кредит, приложение показывает, где экономия больше (обычно в кредите с более высокой ставкой), но выбор оставляет пользователю. Варианты: «всё в ипотеку», «сначала дорогой кредит», «вручную».

### 3.4. Деньги — доходы и расходы

- Быстрое добавление операции в 2–3 касания: сумма, категория, дата (по умолчанию сегодня), необязательная заметка.
- **Доходы:** зарплата (основная), премия (нерегулярная), другое.
- **Расходы, базовые категории:** продукты, машина, дети, дом и коммуналка, здоровье, развлечения, кафе и рестораны, подписки, одежда, связь, другое. Категории можно добавлять, переименовывать и скрывать.
- Платежи по кредитам из приложения автоматически попадают в отдельную системную категорию «Кредиты», их не нужно вводить вручную.
- Месячная сводка: доход, расходы, платежи по кредитам, остаток. Столбчатая диаграмма по категориям.
- Сравнение с обычным уровнем: у каждой категории видно, выше или ниже нормы текущий месяц.

## 4. Расчёты

### 4.1. Аннуитет

- Месячная ставка: `i = годовая ставка / 12 / 100`
- Платёж: `P = S × i / (1 − (1 + i)^(−n))`, где `S` — остаток, `n` — число месяцев.
- Каждый месяц: проценты `= остаток × i`, в основной долг идёт `P − проценты`.

### 4.2. Досрочное погашение

- **Уменьшить срок:** платёж остаётся прежним, остаток уменьшается на сумму досрочки, срок пересчитывается: `n = −ln(1 − S × i / P) / ln(1 + i)`.
- **Уменьшить платёж:** срок остаётся прежним, платёж пересчитывается по формуле аннуитета от нового остатка.
- **Ежемесячная прибавка** (+5/10/20 тыс.) моделируется помесячно: каждый месяц обычный платёж плюс досрочка в выбранном режиме.
- **Экономия на процентах** = сумма процентов по текущему графику − сумма процентов по сценарию.

### 4.3. Точность

Расчёт помесячный и упрощённый: без учёта точного числа дней в месяце и особенностей конкретного банка. Расхождение с графиком банка возможно на небольшие суммы. Пользователь может в любой момент поправить фактический остаток, и прогноз пересчитается.

## 5. Сколько можно направить на досрочку

Считается для каждого месяца:

```
Свободно = Регулярный доход
         − Обязательные платежи по кредитам
         − Обычные расходы
```

- **Регулярный доход** — зарплата (среднее за последние 3 месяца или значение, заданное вручную).
- **Обычные расходы** — медиана расходов по каждой категории за последние 3 месяца. Медиана, а не среднее, чтобы разовая крупная покупка не искажала норму. Пока истории мало (первые месяцы), используется то, что есть, с пометкой «прогноз неточный».
- **Премии** в регулярную сумму не входят. Когда записывается премия, приложение отдельно предлагает сценарий разового погашения: «Если внести эту премию, ипотека закроется на N месяцев раньше».
- Подушка безопасности по желанию пользователя не резервируется.
- Итог показывается как «можно направить до X ₽», а не как требование. Если сумма отрицательная, приложение честно показывает, что в этом месяце расходы выше дохода.

## 6. Подсказки (простые правила)

Каждая подсказка короткая, с конкретной цифрой и пояснением, откуда она взялась. Не больше одной на главной и короткий список на отдельном экране.

Примеры правил:

1. **Категория выше нормы:** расходы в категории в текущем месяце выше медианы за 3 месяца более чем на 25% (и минимум на 2 000 ₽). «На кафе в этом месяце ушло 9 400 ₽, обычно около 6 000 ₽».
2. **Подписки:** сумма подписок за месяц и её годовой эквивалент. «Подписки — 2 300 ₽ в месяц, это 27 600 ₽ в год».
3. **Свободный остаток:** «В этом месяце можно направить до 14 000 ₽. Это приблизит закрытие ипотеки на 2 месяца».
4. **Премия:** после записи премии предлагается сценарий разового погашения.
5. **Ближайший рубеж:** «До отметки 25% выплаченного долга осталось 180 000 ₽».
6. **Какой кредит выгоднее гасить:** если ставка потребительского кредита выше ставки ипотеки, приложение показывает, сколько экономии даёт досрочка именно туда.
7. **Напоминание о вводе:** если трат не было 7 дней, мягкое напоминание (по желанию).

Ни одна подсказка ничего не делает сама: всегда только «посмотреть сценарий» или «закрыть».

## 7. Дизайн

- Стиль нативных приложений Apple: системный шрифт SF Pro, много воздуха, ничего лишнего.
- **Крупные цифры** для главных значений (год закрытия, остаток, свободная сумма); подписи мелкие и серые.
- Карточки с мягкими скруглёнными углами на фоне светло-серого, как в «Настройках» iOS.
- Один акцентный цвет (спокойный зелёный — «прогресс к свободе»), красный только для превышений.
- Графики: тонкие линии, минимум осей и подписей, подробности по касанию.
- Светлая и тёмная тема автоматически, по системным настройкам.
- Учёт увеличенного шрифта в системе и работа с VoiceOver.
- Маленькие празднования рубежей: 10%, 25%, 50%, 75% выплаченного долга и закрытие кредита.

## 8. Данные

Сущности:

- **Кредит:** название, тип (ипотека/потребительский), исходная сумма, текущий остаток, ставка, платёж, оставшийся срок, день платежа, дата начала.
- **Досрочное погашение:** кредит, дата, сумма, режим (срок/платёж).
- **Корректировка остатка:** кредит, дата, фактический остаток по данным банка.
- **Операция:** тип (доход/расход), сумма, категория, дата, заметка.
- **Категория:** название, иконка, тип, регулярная или нет, скрыта или нет.
- **Настройки:** регулярный доход вручную (необязательно), напоминания.

Хранение: локально на устройстве (`localStorage`). Экспорт и импорт в JSON для резервной копии.

## 9. Технологии

Mac нет, поэтому приложение делается как **PWA** — веб-приложение, которое ставится на iPhone через Safari («Поделиться → На экран „Домой“») и открывается как обычное приложение: на весь экран, со своей иконкой.

Почему PWA, а не Expo (React Native):

- Чтобы установить Expo-сборку на свой iPhone не на 7 дней, нужен платный аккаунт Apple Developer (99 $ в год). PWA ставится бесплатно и без App Store.
- Вся разработка и проверка идут на Windows, в браузере.
- Обновления приходят сами при следующем открытии.
- Для этого приложения (формы, расчёты, графики) возможностей веба достаточно.

Стек первой версии (подробно — в [PLAN.md](PLAN.md)):

- **Один файл `index.html`**: разметка, стили и JavaScript внутри. Без сборки, npm и внешних библиотек.
- **Данные** — один JSON-объект в `localStorage`, суммы в копейках. Только на телефоне.
- **Графики** — свои SVG в стиле Apple.
- Внешний вид iOS: системный шрифт (`-apple-system`, то есть SF Pro), учёт «чёлки» и нижней полоски (`safe-area-inset`), нижняя панель вкладок, `prefers-color-scheme` для темы.
- **Расчётное ядро** (кредиты, сценарии, подсказки) — отдельный блок функций без зависимостей от интерфейса. Встроенные тесты открываются по адресу `index.html#test`.
- **Хостинг** — бесплатный статический (GitHub Pages). Он только отдаёт файл, финансовые данные остаются на телефоне.

Ограничения на iPhone:

- Нет виджетов на домашнем экране.
- Тактильный отклик (haptics) в Safari недоступен.
- Без service worker (второй файл) нет надёжной работы без интернета — это версия 2.
- Данные живут в хранилище Safari. Если удалить иконку приложения или очистить данные сайта, они пропадут, поэтому экспорт резервной копии в файл входит в первую версию.
