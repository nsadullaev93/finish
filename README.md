# Финиш

Личное приложение для iPhone, которое помогает быстрее закрыть ипотеку и другие кредиты.

**Открыть:** https://nsadullaev93.github.io/finish/

## Что умеет

- Показывает, в каком месяце и году вы закроете ипотеку, сколько уже выплачено и сколько процентов впереди.
- Считает сценарии досрочного погашения: +5, +10, +20 тысяч в месяц или разовая сумма. Режимы «уменьшить срок» и «уменьшить платёж» показаны рядом.
- Сравнивает, в какой кредит выгоднее направлять деньги: «лавина», «снежный ком» или «сначала ипотека».
- Ведёт доходы и расходы по категориям и считает, сколько можно направить на досрочку.
- Даёт простые подсказки: где траты выше обычного, что даст премия.
- «Копилка» — игра на привычку откладывать каждый день. Сумма растёт на 50% в месяц, но не больше, чем позволяет бюджет. Там же карточки по финансовой грамотности.

## Как установить на iPhone

1. Откройте ссылку выше в **Safari**.
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки — приложение откроется на весь экран.

## Как открыть в Telegram

«Финиш» работает как мини-приложение Telegram. Сервер для этого не нужен: бот — просто кнопка, которая открывает сайт.

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, придумайте имя и адрес бота.
2. `/setmenubutton` → выберите бота → вставьте адрес `https://nsadullaev93.github.io/finish/` → название кнопки, например «Финиш».
3. По желанию: `/newapp` → выберите бота → тот же адрес. Появится ссылка вида `t.me/ваш_бот/finish`.
4. Откройте чат с ботом и нажмите кнопку «Финиш» слева от поля ввода.

Внутри Telegram приложение:
- хранит данные на телефоне через DeviceStorage (нужен Telegram с Bot API 9.0 или новее), а запасную копию — в хранилище браузера;
- берёт светлую или тёмную тему из Telegram;
- закрывает листы кнопкой «Назад» Telegram;
- даёт тактильный отклик при записи трат, ответах на карточки и в «Копилке».

Данные в Telegram и в Safari — отдельные. Чтобы перенести: «Деньги» → шестерёнка → «Скопировать копию текстом», затем на другой стороне «Вставить копию из текста».

## Где хранятся данные

Только на вашем телефоне, в хранилище Safari. Никакой регистрации, сервера и подключения к банку нет. Сайт отдаёт только код приложения.

Раз в месяц сохраняйте резервную копию: «Деньги» → шестерёнка → «Сохранить копию в файл» или «Скопировать копию текстом» (её удобно отправить себе в «Избранное» Telegram). Если удалить иконку или очистить данные Safari, записи пропадут.
